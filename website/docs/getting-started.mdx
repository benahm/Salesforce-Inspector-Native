## Install the package

The latest version is **0.1.0**, package version Id `04tg7000000bCmzAAE`:

- Production or Developer Edition org:
  [install](https://login.salesforce.com/packaging/installPackage.apexp?p0=04tg7000000bCmzAAE)
- Sandbox: [install](https://test.salesforce.com/packaging/installPackage.apexp?p0=04tg7000000bCmzAAE)
- Salesforce CLI:

  ```bash
  sf package install --package 04tg7000000bCmzAAE --target-org <alias> --wait 10
  ```

The [releases](https://github.com/benahm/Salesforce-Inspector-Native/releases) list every version and what changed.

:::warning[Coming from a beta]

A beta version can't be upgraded: uninstall it first (see [Uninstall](./uninstall.md)), then install this version. The
next versions will upgrade it in place.

:::

## Give yourself access

Assign the **SF Inspector Native Admin** permission set to yourself, in Setup or with the CLI:

```bash
sf org assign permset --name sfinative__Admin --target-org <alias>
```

## Add the global action

Open the **SF Inspector Setup** tab (App Launcher, then search "SF Inspector") and click **Add** in the Global Action
section. The action is deployed to the global publisher layout: reload the page when the status shows **Added**.

The **SF Inspector** action now comes first in the global actions menu (`+`) of every Lightning page.

## Give access to other users

In the Access section of the same tab, click **Add users**, choose **User** or **Admin**, then pick users by search,
by profile, or by pasting a list of usernames or emails. See [Setup tab](./setup.mdx).
