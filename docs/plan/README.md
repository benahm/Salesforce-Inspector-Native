# Plan

Ce dossier contient le cadrage de mise en oeuvre de Salesforce Inspector Native.

## Documents disponibles

- `roadmap.md` : roadmap produit par phases de livraison.
- `technical-spec-high-level.md` : spec technique high level de recreation des fonctionnalites majeures de Salesforce Inspector Reloaded dans Salesforce.

## Intention

L'objectif est de recréer une experience familiere pour les utilisateurs de Salesforce Inspector Reloaded, mais sous forme d'application native Salesforce.

Ces documents restent volontairement high level :

- ils aident a prioriser et structurer le produit
- ils proposent une direction technique LWC/Apex
- ils ne figent pas encore les details fins d'implementation
